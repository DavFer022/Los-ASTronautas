## 📌 Resumen del Tema 4

El Tema 4 se centra en el **Análisis Léxico**, la primera fase del proceso de compilación. Este trabajo aborda tanto los fundamentos teóricos como la implementación práctica de analizadores léxicos (lexers).

En la parte teórica, se estudian los autómatas finitos y su relación con las expresiones regulares, la construcción de autómatas a partir de gramáticas regulares, los autómatas de pila, y las metodologías para construir analizadores léxicos tanto desde cero como mediante metacompiladores.

En la parte práctica, se desarrollan cuatro actividades:

1. **Autómatas de pila:** Definición, ejemplos y comparación con AFD/AFND.
2. **Lexer para archivos Docker:** Implementación usando expresiones regulares.
3. **Lexer para subconjunto de Rust:** Implementación con Flex (metacompilador).
4. **FLEX en seguridad informática:** Investigación y reflexión sobre su aplicación.
