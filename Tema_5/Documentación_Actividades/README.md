# Documentación de Actividades - Tema 5

**Análisis Sintáctico**  
**Grupo:** Los ASTronautas  

---

## Descripción

Esta carpeta contiene la documentación del proceso de trabajo colaborativo para el Tema 5: Análisis Sintáctico.

Cada subcarpeta corresponde a una de las actividades solicitadas en el documento de la asignatura, y contiene los archivos de trabajo, borradores, códigos y documentación asociada a cada una.

---

## Estructura de carpetas

| Carpeta | Actividad correspondiente | Descripción |
|---------|--------------------------|-------------|
| `Actividad_1/` | Actividad 1 - Árbol de Sintaxis Abstracta (AST) | Definición, características, ejemplos e implementación en Python |
| `Actividad_2/` | Actividad 2 - Comparación LL vs LR | Tablas comparativas, gramáticas para lenguaje L, implementación de parsers |
| `Actividad_3/` | Actividad 3 - Generadores de Analizadores Sintácticos | Resumen de herramientas, técnicas de manejo de errores |
| `Actividad_4/` | Actividad 4 - Lexer/Parser para Docker Compose | Experimentos de carga, gráficas de tiempo de ejecución |
| `Actividad_5/` | Actividad 5 - Asistente híbrido UnegScript | Lexer con fallback a IA, parser recursivo, ejemplos con errores |

---

## Contenido de cada carpeta

Cada subcarpeta contiene:

- `README.md` con la descripción de la actividad y su estado
- Borradores y notas de investigación
- Códigos fuente (cuando aplica)
- Imágenes o diagramas (cuando aplica)
- Archivos de apoyo
