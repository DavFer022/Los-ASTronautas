## Resumen del Tema 5

El Tema 5 se centra en el **Análisis Sintáctico (Parsing)**, la segunda fase del proceso de compilación. Esta fase toma como entrada la secuencia de tokens generada por el analizador léxico y verifica que la estructura del código fuente cumpla con las reglas gramaticales definidas para el lenguaje, produciendo como salida un **Árbol de Sintaxis Abstracta (AST)**.

El trabajo se ha estructurado en cinco actividades principales:

1. **AST - Árbol de Sintaxis Abstracta:** Definición, características, ejemplos e implementación en Python.
2. **Comparación LL vs LR:** Análisis comparativo de las estrategias descendente (LL) y ascendente (LR), con implementación para un lenguaje L.
3. **Generadores de Analizadores Sintácticos:** Resumen de herramientas (ANTLR, Bison, SLY) y técnicas de manejo de errores.
4. **Lexer/Parser para Docker Compose:** Experimentos de carga con diferentes implementaciones y gráficas de tiempos.
5. **Asistente Híbrido UnegScript:** Lexer con fallback a IA, parser recursivo y sugerencias de corrección.
