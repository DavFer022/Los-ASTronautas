### Para ejecutar la app de pruebas

1. Abra una terminal en la carpeta del repositorio clonado y cambie a la carpeta del ejecutable:

```powershell
cd Tema_3\Documentacion_Actividades\Actividad_2.4\Desarrollo\src\ejemplo-ejecutable
```

2. Ejecute el programa directamente en Windows:

```powershell
.\PgnAutomata.exe
```

3. O bien, si prefiere usar `dotnet`, ejecute:

```powershell
dotnet PgnAutomata.dll
```

4. En macOS o Linux, use también `dotnet` desde la misma carpeta:

```bash
dotnet PgnAutomata.dll
```

5. Siga las instrucciones que aparezcan en pantalla para seleccionar ejemplos, ingresar movimientos personalizados o ejecutar todas las pruebas.
